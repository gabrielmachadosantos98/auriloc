The problem

Location testing on iPhone is slow and hard to repeat

If your app depends on where the user is, every test means a Mac, a simulator that isn't a real device, or a walk around the block.

Xcode needs a Mac

Teams building with React Native or Flutter on Windows have no native way to move a real iPhone.

Manual trips don't repeat

Walking or driving to reproduce a geofence bug costs hours and never follows the same path twice.

Spoofing apps aren't test tools

Consumer location changers are built for games. No API, no scripting, nothing your CI can run.

Features

Everything you need to test location, on the device your users have

Fixed location

Click anywhere on the map or paste coordinates. The iPhone is there instantly.

Routes at real speed

Draw a path, pick walking, cycling or driving speed, and watch the device move one update per second.

GPX playback

Replay recorded tracks at their original pace to reproduce real trips exactly.

CLI and HTTP API

Everything on the map is scriptable. Drive the device from Appium, Maestro or any test runner.

No jailbreak, no admin

Uses Apple's developer interface over USB. Runs as a normal Windows user.

Open-source core

The agent is GPL-3.0. Inspect it, extend it, run it in your own pipeline.

How it works

From cable to moving iPhone in three steps

  1. 1

    Plug in your iPhone

    Trust the computer and turn on Developer Mode. Auriloc walks you through it.

  2. 2

    Start Auriloc

    The map opens in your browser and connects to the device automatically.

  3. 3

    Click, draw or script

    Set a point, play a route, or call the API from your tests. Stop, and the iPhone returns to real GPS.

terminal
# Pin the iPhone to a location
auriloc set -23.5505 -46.6333

# Replay a recorded trip
auriloc route delivery-run.gpx

# Drive a route at 40 km/h from your test suite
curl -X POST localhost:8765/api/route \
  -H "Content-Type: application/json" \
  -d '{"speed_kmh": 40, "points": [
        {"lat": -23.5552, "lon": -46.6621},
        {"lat": -23.5713, "lon": -46.6449}]}'

FAQ

Questions

Do I need a Mac or a jailbroken iPhone?

No. Auriloc runs on Windows and uses Apple's developer interface over USB. You only need to turn on Developer Mode on the iPhone, which is a standard setting.

Which iPhones and iOS versions are supported?

Any iPhone running iOS 17.4 or later.

Does it work on macOS, Linux or Android?

Windows comes first. macOS and Linux are on the roadmap, and Android support is being considered. Tell us what you need in the waitlist form.

Can apps tell the location is simulated?

Yes. Since iOS 15, apps can detect simulated locations, and Auriloc doesn't try to hide it. That's fine for testing your own app, and it's why Auriloc isn't meant for fooling other apps.

Is it legal?

Simulating the location of your own device for development, testing and demos is a standard practice. Using it to deceive people or services, like faking check-ins or attendance, is prohibited. See the acceptable use policy.

The core agent is free and open source. A Pro plan for teams, with shared scenarios and CI integrations, is planned. Waitlist members get founding-member pricing.
